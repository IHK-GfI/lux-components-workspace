Tooltip nur bei abgeschnittenem Text Aktiviert wird der Tooltip über den Input [luxTooltipIfTruncated]="true" zusammen mit einer Crop-Klasse (hier .lux-crop mit overflow: hidden; white-space: nowrap; text-overflow: ellipsis). luxTooltip, luxTooltipIfTruncated und die Crop-Klasse müssen auf demselben Element liegen.
{{ resizableMessage }}
Das Fenster lässt sich am Griff unten rechts in der Breite ändern. Bei voller Breite bleibt der Tooltip aus. Sobald der Text abgeschnitten wird, erscheint er beim Hover. Mehrzeilig gekürzter Text (line-clamp) Die Erkennung funktioniert auch bei vertikaler Kürzung, z.B. mit der Klasse .lux-crop-2-lines (-webkit-line-clamp: 2). Der Text darf umbrechen, wird aber nach zwei Zeilen ausgepunktet.
{{ resizableMessageMultiline }}
Solange der Text in zwei Zeilen passt, bleibt der Tooltip aus. Wird das Fenster schmaler gezogen und der Text nach der zweiten Zeile abgeschnitten, erscheint der Tooltip beim Hover.
