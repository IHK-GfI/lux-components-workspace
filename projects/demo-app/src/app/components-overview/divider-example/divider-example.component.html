 Diese Property schaltet den Divider von eine absoluten in eine statische Position um.
Das hat zur Folge, dass der Divider sein Parent-Element nicht mehr überragt. Diese Property schaltet den Divider von einer horizontalen in eine vertikale Ansicht um.
Die umgebenden Elemente müssen allerdings auch passend ausgerichtet sein, zum Beispiel wird hier die Ausrichtung für die vertikale Ansicht von "column" zu "row" geändert.
